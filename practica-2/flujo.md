GitFlow y Trunk-Based Development son dos formas diferentes de trabajar con Git.
GitFlow utiliza varias ramas o branches para organizar las diferentes etapas del desarrollo.
Por ejemplo, se pueden crear ramas para nuevas funciones (feature), pruebas (develop) y correcciones (hotfix).
Esto ayuda a mantener el proyecto ordenado, pero también puede hacerlo más complicado.
Trunk-Based Development utiliza principalmente una rama llamada main.
Los desarrolladores agregan cambios pequeños y frecuentes a esta rama principal.
